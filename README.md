# Insurance-Cost-Prediction-project.


A Machine Learning project that analyzes medical insurance data and predicts individual insurance charges based on factors such as age, gender, BMI, number of children, smoking status, and region.

The project includes Exploratory Data Analysis (EDA), data cleaning, preprocessing, feature engineering, statistical analysis, and predictive modeling. The objective is to identify the key factors influencing medical insurance costs and build a model that can accurately predict insurance charges.

## Key Features

* Data exploration and statistical analysis
* Missing value and duplicate value checking
* Exploratory Data Analysis (EDA) with visualizations
* Analysis of relationships between features and insurance charges
* Categorical data encoding
* Feature engineering and preprocessing
* Statistical testing and feature analysis
* Machine Learning model development
* Model performance evaluation

## Dataset Features

* `age` — Age of the individual
* `sex` — Gender
* `bmi` — Body Mass Index
* `children` — Number of children/dependents
* `smoker` — Smoking status
* `region` — Residential region
* `charges` — Medical insurance cost (Target Variable)

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

* SciPy

## Project Workflow

Data Collection → Data Cleaning → EDA → Feature Engineering → Statistical Analysis → Data Preprocessing → Model Building → Model Evaluation

This project demonstrates an end-to-end data science workflow for solving a real-world regression problem using medical insurance data.
